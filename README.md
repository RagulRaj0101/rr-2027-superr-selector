# 🏏 SuperRR Selector – IPL 2027 Auction Strategy

A data-driven cricket analytics project developed for **SupeRR Selector Season 2 – Round 1**, focused on identifying reliable batters and bowlers under pressure for Rajasthan Royals' IPL 2027 auction strategy.

## 🚀 Live Dashboard

[Open the SuperRR Selector Dashboard](https://rr-2027-superr-selector-exppuy6gwkqzj97mjdrwjq.streamlit.app/)

## 📊 Project Overview

- 20 shortlisted players
- 10 batters and 10 bowlers
- 5 pace bowlers and 5 spin bowlers
- Historical IPL and T20I performance analysis
- Pressure-based player evaluation and ranking

## 🧰 Technology Stack

- Python
- Pandas and NumPy
- Plotly
- Streamlit
- Google Colab

## 📁 Repository Structure

- `app.py` – Interactive Streamlit dashboard
- `requirements.txt` – Python dependencies
- `RR_2027_Master_Shortlist.csv` – Final player shortlist
- `RR_2027_Methodology.json` – Analysis methodology
